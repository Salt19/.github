# SALT19 GitHub Standards

This repository contains the public organization profile and default community-health files for the SALT19 GitHub organization.

## Purpose

The files here define baseline contribution, security, issue-reporting, and pull-request expectations for SALT19 repositories that do not provide more specific repository-level guidance.

Repository-specific instructions always take precedence when present.

## Organization profile

The public SALT19 organization profile is maintained in [`profile/README.md`](profile/README.md).
