# SALT19 Support

Use the repository's issue tracker for reproducible bugs, documentation defects, and public feature requests when that repository enables issues.

For general company inquiries, commercial discussions, private customer matters, or questions that should not be public, contact:

- General: info@salt19.com
- Engineering: engineering@salt19.com
- Website: https://salt19.com

For security-sensitive matters, follow [`SECURITY.md`](SECURITY.md) instead of opening a public issue.

Repository-specific support instructions take precedence when present.
